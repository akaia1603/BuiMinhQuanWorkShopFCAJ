## Bước 2 — Upload và bật static hosting

1. Upload file `index.html` lên bucket.

![Upload file lên bucket](/images/5-Workshop/5.4-S3-CloudFront/04-upload-files.png)

*Đang upload `index.html` lên bucket.*

2. **Properties → Static website hosting → Enable**, Index document: `index.html`.

![Static website hosting đã bật](/images/5-Workshop/5.4-S3-CloudFront/05-static-hosting-enable.png)

*Static website hosting: Enabled.*

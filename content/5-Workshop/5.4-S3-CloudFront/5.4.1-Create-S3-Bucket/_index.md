## Step 1 — Create the S3 bucket

1. Create an S3 bucket (name must be globally unique) in `ap-southeast-1`.

![Creating the S3 bucket](/images/5-Workshop/5.4-S3-CloudFront/02-create-bucket.png)

*The "Create bucket" wizard.*

2. Untick **Block all public access** to allow public reads.

![Bucket created](/images/5-Workshop/5.4-S3-CloudFront/03-bucket-created.png)

*The bucket is created and listed.*

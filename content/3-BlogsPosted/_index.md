During my internship, I actively shared technical insights and architectural case studies with the community. Below is the list of technical blogs I authored and posted on the [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj) community page:

### [Blog 1 - INTRODUCING GUARDRAILS IN AMAZON BEDROCK KNOWLEDGE BASES](3.1-Blog1/)

This blog presents an enterprise RAG chatbot architecture on AWS built with Amazon Bedrock Knowledge Bases, Amazon OpenSearch Serverless, and Bedrock Guardrails.

### [Blog 2 - REAL-TIME ANALYSIS OF CUSTOMER SENTIMENT USING AWS](3.2-Blog2/)

This blog presents a near-real-time customer sentiment analysis pipeline using Amazon Comprehend, API Gateway, SQS, Step Functions, DynamoDB, Kinesis, and QuickSight.

### [Blog 3 - EXTRACT GRANULAR SENTIMENT IN TEXT WITH AMAZON COMPREHEND TARGETED SENTIMENT](3.3-Blog3/)

This blog introduces Amazon Comprehend Targeted Sentiment, which identifies entity-level sentiment (co-reference groups of mentions) beyond whole-document analysis.
